# Practical 01 - Student Admission Management

-> Aim : Develop a Student Admission Management Module using OOP concepts.

-> Concepts Used : 

- Class
- Object
- Constructor
- Access Modifiers
- Encapsulation

-> Features :

- Student admission number
- Student name
- Course
- Semester
- Admission fees
- Scholarship calculation
- Final fees calculation

-> Technologies :

- C#
- .NET Console Application

-> Output :

The application accepts student details and calculates the applicable scholarship and final admission fees.
